# SGF Frontend

Frontend do **SGF - Sistema de Gestao Facilitada**.

Esta aplicacao foi criada com React, TypeScript e Vite.

## Comandos

```powershell
npm install
npm run dev
npm run build
```

Por padrao, o frontend consulta a API em:

```text
http://localhost:5206
```

Para alterar esse endereco localmente, crie um arquivo `.env` nesta pasta com base em `.env.example`.
